# Выделенный сервер SECTOR 09

Одна серверная комната использует ту же симуляцию, что и браузерный хост. Сервер рассчитывает движение, попадания, здоровье, захват точек и билеты. Входящие координаты и здоровье клиента игнорируются. Боты заполняют карту независимо от числа подключённых людей.

## Локальный запуск

Нужен Node.js 22 или новее:

```sh
npm ci
npm test
npm run build
npm start
```

Игра доступна на `http://localhost:8080`, сервер для сетевой вкладки — `ws://localhost:8080`. Проверка работоспособности: `http://localhost:8080/health`.

Переменные окружения:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `8080` | HTTP/WebSocket-порт; сервер слушает `0.0.0.0` |
| `BOTS` | `23` | Количество ботов, от 0 до 31 |
| `MAX_PLAYERS` | `16` | Максимальное число подключений людей, от 2 до 32 |
| `DIFFICULTY` | `regular` | Сложность ботов: `recruit`, `regular`, `veteran` |
| `MAP_ID` | `port` | Карта матча. `quarry` включает карьер «Перевал» с техникой. |

Это ограничения конфигурации, а не проверенная нагрузочная вместимость публичного сервера. Автоматические проверки включают двух сетевых клиентов и полный бой 16 ботов. После победы начинается новый раунд через 12 секунд. Текущий матч и статистика хранятся в памяти.

## Docker

```sh
docker build -t gpt-test .
docker run --rm -p 8080:8080 -e BOTS=12 -e MAX_PLAYERS=16 gpt-test
```

Образ собирает клиент и запускает тесты, затем запускает сервер от непривилегированного пользователя. Локальная среда разработки проекта не имела Docker, поэтому сам контейнер здесь не запускался.

## Render

В репозитории подготовлен `render.yaml` с одним Docker Web Service на плане `free`. Чтобы создать сервис, подключите репозиторий как Blueprint в своём аккаунте Render. Наличие этого файла ничего не создаёт и не включает оплату само по себе.

После развёртывания используйте адрес `wss://<адрес-сервиса>.onrender.com` в сетевой вкладке игры. Для страницы на HTTPS требуется защищённое соединение `wss://`; TLS завершает хостинг или ваш reverse proxy.

Бесплатный сервис Render может засыпать после 15 минут без входящего трафика; пробуждение занимает около минуты. Если первое соединение не удалось, откройте HTTPS-адрес `/health`, дождитесь ответа и подключитесь снова. У бесплатного плана есть ограничения ресурсов и трафика: [документация Render](https://render.com/docs/free). Подготовленная конфигурация соответствует [спецификации Blueprint](https://render.com/docs/blueprint-spec).

## Редактор карт

Откройте `https://<адрес-сервиса>/editor`. На GitHub Pages редактор доступен по пути `/gpt-test/editor/` для локальной работы и скачивания JSON. Для публикации откройте редактор на том же Node-сервере, который раздаёт игру.

Чтобы включить сохранение, добавьте в окружение сервиса две переменные.

- `EDITOR_PASSWORD` — отдельный случайный пароль длиной от 24 символов из латинских букв и цифр. Его нужно ввести через кнопку **Подключить GitHub**.
- `EDITOR_GITHUB_TOKEN` — fine-grained personal access token с доступом только к `fen417/gpt-test` и правом **Contents → Read and write**. Правила ветки должны разрешать учётной записи токена коммиты в `main`. Вводите токен только в настройках окружения сервиса. [Инструкция GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens#creating-a-fine-grained-personal-access-token)

После обновления сервиса выберите карту. Перетаскивайте объекты на схеме сверху или под углом. Чтобы поставить новый объект, перетащите его из библиотеки или выберите ассет и щёлкните по карте. Для точного размещения используйте координаты X/Z и шаг привязки. Правый клик с перетаскиванием перемещает камеру, колёсико меняет масштаб. Под углом средняя кнопка позволяет вращать камеру. `Ctrl+Z` отменяет правку, `Delete` удаляет выбранный объект.

Препятствия и декорации можно добавлять, дублировать и удалять. Точки захвата, базы и узлы маршрутов остаются частью игровой схемы. Их можно двигать. Перенос участка маршрута сдвигает его концы и пересчитывает соседние участки. Библиотека использует модели выбранной карты и образцы процедурных текстур игры. Редактор показывает упрощённую геометрию. Фоновое окружение за границами карты формируется игровым кодом.

**Сохранить в GitHub** создаёт коммит в `main`, меняющий `shared/maps/port.json` или `shared/maps/quarry.json`. Эти данные использует и браузер, и сервер. Если файл успели изменить параллельно, редактор сохраняет локальный черновик и предлагает сверить версию. Чтобы изменения появились в игре, дождитесь развёртывания коммита и обновите страницу. При автодеплое выделенного сервера его текущий матч перезапустится.

## Текущие игровые ограничения

Реализованы захват пяти точек на каждой карте — «Рубеж» (360 × 360 м) и «Перевал» (896 × 896 м), билеты, четыре класса, лечение, снабжение боеприпасами, обнаружение противников, гранаты, перезарядка, возрождение и боты с поиском пути. Максимум раунда — 16 минут. Протокол версии 8 отклоняет клиентов со старой картой. Пока нет механики поднятия погибших, отдельных отрядов, разрушения зданий, аккаунтов и сохранения прогресса. При завершении процесса матч сбрасывается. Сервер подходит для проверки игры и небольших комнат; сетевой бой в публичном интернете требует собственных игровых проверок задержек и нагрузки.
