# Reload recordings

These are the public high-quality previews of sounds released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The source cuts in [cuts.json](cuts.json) specify where each recording is used. The runtime bank is trimmed, leveled, faded, converted to mono and encoded in Opus and AAC. Some recordings use replicas or Foley for the fictional weapons.
