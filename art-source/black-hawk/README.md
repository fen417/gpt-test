# UH-60 «Чёрный Ястреб»

`black-hawk.blend` содержит редактируемые детали фюзеляжа, салона, винтов и минигана. Три исходные коллекции соответствуют трём уровням детализации. Скрипт Blender `build_black_hawk.py` создаёт проект и игровой экспорт `src/assets/black-hawk/black-hawk.glb`. Для сборки из скрипта запустите Blender с аргументами `--background --factory-startup --python art-source/black-hawk/build_black_hawk.py`.

GLB содержит уровни `LOD0`, `LOD1` и `LOD2`. В каждом сохраняются габариты, проёмы и точки вращения. Движок отдельно вращает несущий винт, рулевой винт и миниган. Положение кресел и секторы стрельбы заданы в `shared/vehicles.js`.

В «Перевале» по одному вертолёту стоит на каждой базе. Пилот управляет курсом и скоростью через WASD, набирает высоту клавишей прыжка и снижается клавишей приседания. Сменить место и выйти можно после посадки. Третье место управляет миниганом слева, четвёртое и пятое стреляют из личного оружия через правый проём.

Для размещения в сценарии на основе `CampaignSimulation` добавьте в описание миссии массив `blackHawks` с одним или двумя объектами. Поля `x` и `z` задаются в метрах на свободной площадке, `yaw` в радианах. В кампании подбитый вертолёт не возрождается.

```json
{
  "blackHawks": [
    { "id": "support-black-hawk", "team": 0, "x": -170, "z": -141, "yaw": -1.57 }
  ]
}
```

Для сетевых матчей клиент и выделенный сервер должны использовать протокол 33.
