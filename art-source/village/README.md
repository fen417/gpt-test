# Деревня «Сухой ветер»

В [dry-wind.blend](dry-wind.blend) две коллекции. Base содержит всю основную геометрию, которая загружается при любом качестве. High detail добавляет фасады, декоративные элементы домов, рынка, колодцев, растительности и корпуса корабля. При включении слоя High упрощённые кроны заменяются детализированными.

Координаты и высоты берутся из текущей карты в игре. Игровые коллизии, точки захвата и навигация продолжают использовать данные карты. После изменения планировки обновите экспорт. В игре действует проверка совпадения планировки, а в редакторе по-прежнему используется геометрия, которую можно перестраивать при перемещении объектов.

Из корня проекта с Blender 5.3:

~~~sh
node scripts/export-village-source.mjs .perf-local/village-bake
blender -b --python-exit-code 1 --python art-source/village/build_village.py -- .perf-local/village-bake
node scripts/pack-village.mjs .perf-local/village-bake
~~~

Сборка создаёт .blend, упакованные GLB для Low и High, маску дорог, текстуру скал и манифест. Не объединяйте кварталы в один объект. Отдельные границы секторов позволяют движку отбрасывать невидимую геометрию.
