# Руки от первого лица

Модель, скелет и текстуры создал **bobeer**. Ассет называется **Gloves for fps game** и распространяется по **CC BY 4.0**. Сведения об авторе и лицензии также записаны в метаданных исходного GLB. [Страница модели](https://sketchfab.com/3d-models/gloves-for-fps-game-3b321da343714e9597e3e86af8a0a7a6) · [Лицензия CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [Исходный GLB в Objaverse](https://huggingface.co/datasets/allenai/objaverse/resolve/main/glbs/000-064/3b321da343714e9597e3e86af8a0a7a6.glb)

SHA-256 исходного GLB — `973ed7fb6154ae8e3d542a991d562669bc9fbc29fa893844de286ea0300f218b`.

`bobeer.blend` содержит исходную геометрию, риг и упакованные текстуры 1024×1024. При экспорте запястья подогнаны под манжеты, рукава адаптированы к движению от плеча и сохранены исходные UV. Точки контакта для винтовок, дефибриллятора и бинокля заданы по игровым моделям в `scripts/build-fps-hands.mjs`. Для пистолетов и переноски ящиков использованы подготовленные позы Cransh из экспорта cktang88. Атрибуция этих исходников хранится в [djmaesen-arms/README.md](../djmaesen-arms/README.md).

Для пересборки геометрии запустите `npm run assets:hands` из корня репозитория. Скрипт использует Blender из `BLENDER_EXE`, штатную установку Blender 5.3 на Windows или команду `blender` из PATH. Игровая геометрия загружается из `src/assets/fps-hands.bin.gz`. Карты материала рядом в папке `fps-hands` экспортированы из исходного атласа в WebP. Красный канал ORM хранит окклюзию, зелёный — шероховатость, синий — металличность.
