# Порт «Рубеж»

[Исходная сцена Blender](port-rubezh.blend) содержит редактируемые объекты в коллекциях **Core geometry** и **High detail**. Вода в сцене служит ориентиром. В игре у неё собственная анимация.

Расстановка техники, складов, кранов и укрытий берётся из игровой карты. После изменения планировки экспорт нужно собрать заново, чтобы модель совпадала с проходами и коллизиями. Пока новая сборка карты отсутствует, игра использует геометрию редактора.

Команды из корня проекта для Blender 5.3

```sh
node scripts/export-port-source.mjs
blender -b --python-exit-code 1 --python art-source/port/build_port.py -- .perf-local/port-bake
node scripts/pack-map.mjs .perf-local/port-bake src/assets/port
```

Игра загружает базовый слой для любого профиля. При максимальном качестве с высокой детализацией подгружается второй слой. Экспорт объединяет объекты только внутри секторов и сохраняет достаточный зазор между тонкой разметкой, облицовкой и поверхностями под ними.
