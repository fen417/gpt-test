# Музыка «Колонны»

Положи дорожки в эту папку. Имена можно изменить в `public/campaign/m03/mission.json`, в объекте `music`.

| Файл | Использование |
| --- | --- |
| `convoy.ogg` | Тихая подложка поездки. Затухает между 01:20 и 01:40. |
| `ambush-hit.ogg` | Короткий акцент. Игра запускает файл вместе со взрывом ведущего танка. Помести пик атаки в начало файла. |
| `combat.ogg` | Основная бо́евая петля через 0,4 с после первого попадания. Пока нет `interior.ogg`, внутри зданий звучит та же петля на меньшей громкости. |
| `combat-drums.ogg` | Синхронный слой барабанов на тревоге 3. Сделай его той же длительности и с той же первой долей, что и `combat.ogg`. |
| `interior.ogg` | Редкая подложка внутри дома при низкой тревоге. |
| `finale.ogg` | Оркестровая петля с начала финальной сцены в штабе. |

Рекомендуемая длительность петель — 60–90 секунд. Для боя в диздоке указан темп 140 BPM. Файлы должны иметь бесшовный стык без паузы на конце. Удар засады — отдельный короткий файл.

Общий бюджет музыки миссии — 3 000 000 байт в сборке. Дорожки подгружаются при запуске «Колонны», включаются по времени симуляции и подчиняются настройке громкости музыки. Во время реплики музыка приглушается. Гибель союзника даёт две секунды тишины. Отсутствующий файл оставляет переход без музыки.

Для записей диалогов можно указать `"audio": "voice/<имя>.ogg"` в соответствующей строке `public/campaign/m03/ru.json`. Без записи будет показан субтитр.
