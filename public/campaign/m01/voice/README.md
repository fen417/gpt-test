# Озвучка

Добавлены 68 временных синтезированных записей (около 684 КБ).
Использован русский голос Microsoft Pavel и восемь профилей тембра/темпа
для персонажей. Это обработанные варианты одного системного голоса,
а не актёрские записи и не клонирование чужих голосов.

Имена файлов и говорящие: `docs/Миссия-1-реплики-для-озвучки.md`.
Пути, длительность и приоритет каждой строки: `../ru.json`.
Формат: Ogg Opus, моно, 24 кбит/с; все записи вместе до 1 МБ.
Файлы загружаются только в кампании. Не объединять реплики в один файл.

Профили и измеренные длительности: `manifest.json`. Перегенерация на Windows
с PowerShell 7 и установленным Microsoft Pavel:
`node scripts/synthesize-campaign-voice.mjs` из корня проекта.
Файлы WAV остаются только в игнорируемом каталоге `.perf-local/`.
Для замены актёрской озвучкой достаточно сохранить имена файлов
и обновить длительность строки в `ru.json`.
