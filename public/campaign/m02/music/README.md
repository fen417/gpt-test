# Музыка миссии 2 «Рассвет над Аль-Хадрой»

Файл находится по пути `public/campaign/m02/music/m02-dawn.ogg`.
Измеренная длительность исходного OGG: **187,5735 с (03:07,574)**.

Музыка запускается в момент передачи управления танком. В первой части трек играет непрерывно с 00:00, затем повторяется только боевой участок:

- **loopStart = 100.193** (01:40,193)
- **loopEnd = 179.643** (02:59,643)
- **Длительность повторяемой части = 79.450 с**
- **Окончание 02:59,643–03:07,574 не воспроизводится в боевом цикле** (это затухающее завершение записи).

Зацикливание выполняет Web Audio в браузере. Не требуется создавать и загружать отдельный обрезанный файл: полный OGG сохраняет вступление, а после 02:59,643 проигрыватель возвращается на 01:40,193.

Тайминги задаются в `public/campaign/m02/mission.json`. Они изменяемые — диздок ещё развивается. При паузе музыка останавливается, а после возобновления переходит к соответствующей точке музыкальной петли на игровом таймере. Даже без аудио игровые события срабатывают от времени симуляции, включая появление врагов на 13-й секунде.

Точка повтора выбрана под музыкальную фразу и не включает финальное затухание. Если на некоторых устройствах слышится щелчок на стыке, следующим шагом будет короткий кроссфейд, а не перенос таймингов игровых событий.
