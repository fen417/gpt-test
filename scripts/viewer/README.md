# SECTOR 09 — просмотр анимаций

1. Распакуйте архив целиком.
2. Запустите `Start.cmd`. Просмотрщик откроется в браузере. Оставьте окно запуска открытым.
3. Для выхода закройте окно запуска или нажмите в нём Ctrl+C.

На компьютере нужен Node.js в PATH и браузер с WebGL2. Сервер работает только на 127.0.0.1. После распаковки просмотрщик использует локальные файлы, включая модели и текстуры.

## Управление

- В режиме «В игре» позы и хват воспроизводит тот же контроллер, который работает в матче. «Исходный клип» показывает дорожки самого клипа, без игрового наложения оружия.
- Выберите команду, оружие и анимацию. В режиме прицеливания и стрельбы можно задать поворот и наклон оружия. Для смены оружия выбирается второй образец.
- Тяните сцену мышью для вращения камеры, пользуйтесь колесом для приближения. Крупные планы показывают выбранного бойца. При выборе обеих команд крупный план фокусируется на регулярной армии.
- Пробел ставит воспроизведение на паузу, когда фокус вне поля ввода. Ползунок позволяет перейти к нужному моменту. Кнопки рядом с паузой двигают симуляцию по одному кадру.
- В разделе «Параметры симуляции» можно выбрать LOD и включить имитацию сетевых снимков.

В списке десять игровых образцов. Некоторые используют одну модель от третьего лица, как и в матче. В папке `licenses` находятся ссылки на источники и условия использования ассетов.
