# SECTOR 09

Браузерный 3D-шутер: захват точек, командный бой насмерть, одиночная игра с ботами, сюжетная кампания и выделенный авторитетный сервер.

- [Основная версия](https://fen417.github.io/gpt-test/) — `main`, сетевая игра.
- [Тестовая версия](https://fen417.github.io/gpt-test/test/) — `remaster/pbr-ktx2`, экспериментальная графика, без сетевой игры и облачного профиля.

## Запуск

Node.js 24+, npm. Клиент: Three.js 0.181.2, Vite, WebGL 2 / WebGPU. Сервер: Node.js / WebSocket.

```sh
npm ci
npm run dev
```

Откройте адрес Vite (обычно http://127.0.0.1:5173/). Для production: `npm run build`, затем `npm run preview`. PBR-ассеты уже в репозитории; если они отсутствуют, predev/prebuild готовят их автоматически. Для автономной сборки установите `S09_PBR_SKIP=1` (при наличии готового пакета).

## Управление

WASD — движение, мышь — обзор, ЛКМ/ПКМ — огонь/прицел, Shift — бег, C — присесть, пробел — прыжок, R — перезарядка, 1/2 — оружие, 3/X — снаряжение, G — граната (или выброс оружия на соответствующей карте TDM), E — взаимодействие, F — место в технике, V — камера техники, Tab — счёт, Esc — меню. Назначения меняются в настройках.

## Архитектура

| Каталог | Назначение |
|---|---|
| `src/` | Клиент, рендер, звук, UI, сетевое предсказание |
| `shared/` | Симуляция, карты, коллизии, оружие, протокол |
| `server/` | Авторитетный сервер, комнаты, профили |
| `public/` | Ресурсы кампании, KTX2, декодер Basis |
| `art-source/` | Редактируемые модели, исходный звук, скрипты генерации |
| `scripts/` | Сборка, конвертация ассетов, диагностика |
| `test/` | Основные регрессионные проверки |

Версии и патчноуты: `shared/releases.js`, `package.json`, протокол — `shared/world.js`. Не меняйте сетевой протокол без согласованного обновления сервера и клиента. Старый редактор процедурных карт удалён; игровые карты и их исходники сохранены.
