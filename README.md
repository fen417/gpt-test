# SECTOR 09

Браузерный 3D-шутер про бой за территорию. Самостоятельный игровой прототип, вдохновлённый командными военными шутерами. Игра запускается в браузере без установки и регистрации.

**Играть:** https://fen417.github.io/gpt-test/

## Что работает

- Промышленная карта 360 × 360 м с пятью точками захвата, тремя проходными складами, контейнерными дворами и фланговыми маршрутами.
- Карьер «Перевал» 896 × 896 м с пятью точками захвата, затяжными спусками и насыпями. Водоотлив, Верхняя терраса и другие ориентиры дают укрытия вдоль объездных дорог.
- По два двухместных квадроцикла и одному пятиместному хамви с пулемётом на каждой базе. Пассажиры используют личное оружие, в хамви стреляют через боковое окно. Боты собирают экипаж на базе и делают остановки у укрытий. Гранаты повреждают технику сильнее пуль.
- Две команды, 600 билетов, победа через удержание территории и потери противника.
- Четыре класса: штурмовик, медик, поддержка и разведчик; разные оружие, магазины, темп огня и способности.
- Прицеливание, отдача, перезарядка, ограниченные боеприпасы, гранаты, бег, приседание и прыжок.
- Попадания с проверкой препятствий, урон в голову, восстановление здоровья и возрождение на базе или своей неоспариваемой точке.
- Боты ищут путь, захватывают точки, стреляют очередями и возвращаются после гибели. Три уровня сложности: новобранцы, обычные бойцы, ветераны. По умолчанию реакция замедлена, дальность обнаружения ограничена, между очередями есть паузы.
- Сетевые комнаты по коду и отдельный авторитетный WebSocket-сервер.
- Миникарта, компас, счёт, журнал устранений, настройка угла обзора и качания камеры.
- Фактурные материалы, атмосферное освещение, анимации бойцов и оружия, следы попаданий и эффекты взрывов.
- Оригинальная музыка меню, пространственные звуки оружия, шагов, перезарядки и окружения; раздельная громкость музыки и эффектов.

Это ранняя версия: здесь нет разрушаемых зданий, поднятия погибших союзников, управляемых отрядов, прогрессии и полноценного античита. Интерьеры есть в трёх открытых складах; остальные здания служат внешними укрытиями. Стабильные 16 игроков в разных сетях ещё требуют нагрузочных испытаний.

## Как играть

1. Открой игру в актуальном настольном Chrome, Edge или Firefox с аппаратным ускорением.
2. Введи позывной и выбери класс.
3. Выбери карту, сложность и плотность: 16, 24 или 32 бойца вместе с ботами. По умолчанию — 24 бойца и обычная сложность.
4. **«На поле боя»** запускает локальный матч. Захватывай точки: стой в зоне без противника. Удержание большинства точек уменьшает билеты врага.
5. После высадки действует двухсекундная защита, которая снимается при открытии огня или броске гранаты. Максимальная продолжительность раунда — 16 минут.

Музыка меню начинается после первого клика или клавиши: браузеры блокируют звук до взаимодействия. Кнопка **«Музыка»** включает/выключает партитуру; отдельные ползунки громкости находятся в меню Esc. Настройки обзора, звука, сложности и плотности сохраняются в браузере.

| Клавиша | Действие |
| --- | --- |
| WASD | Движение |
| Мышь | Обзор |
| ЛКМ / ПКМ | Огонь / прицел |
| Shift | Бег |
| C / левый Ctrl | Присесть |
| Пробел | Прыжок |
| R | Перезарядка |
| Q | Способность класса |
| G | Граната |
| E | Сесть в технику / выйти |
| V | Сменить место в технике на малой скорости |
| Tab | Таблица игроков |
| Esc | Меню |

Если встроенный просмотрщик блокирует захват мыши, выбери **«Играть без захвата мыши»**. В этом режиме обзор работает при движении мыши с зажатой ПКМ или стрелками клавиатуры. Для привычного FPS-управления открой ссылку в отдельной вкладке браузера.

Способности: штурмовик восстанавливает здоровье, медик лечит находящихся рядом союзников, поддержка пополняет резерв патронов, разведчик обнаруживает ближайших врагов на миникарте. Способности имеют перезарядку.

## Игра с друзьями на GitHub Pages

Хозяин нажимает **«Создать комнату»** и передаёт шестизначный код. Карту можно выбрать до создания комнаты или в лобби. Остальные выбирают **«Войти по коду»**. Матч рассчитывает браузер хозяина; обмен состоянием идёт через WebRTC. PeerJS Cloud используется для поиска соединения.

Хозяин должен держать вкладку открытой и активной. При его выходе комната закрывается. Публичный сервис сигнализации и прямое WebRTC-соединение зависят от доступности сервиса, NAT и сети: подключение не гарантируется во всех сетях. Собственный TURN-сервер в комплект не входит. При невозможности соединения игра показывает ошибку; для постоянного матча используй выделенный сервер.

## Локальная разработка

Нужен Node.js 22 или новее.

```sh
npm ci
npm run dev
```

Открой напечатанный Vite адрес. Сборка и проверки:

```sh
npm test
npm run build
npm run preview
```

## Выделенный сервер

```sh
npm ci
npm run build
npm start
```

Сервер обслуживает клиент на `http://localhost:8080` и WebSocket на `ws://localhost:8080`. В меню раскрой **«Выделенный сервер»** и введи адрес. Для клиента на HTTPS (включая GitHub Pages) нужен публичный `wss://` с доверенным сертификатом; незашифрованный `ws://` допустим только локально.

Переменные окружения: `PORT` (8080), `BOTS` (23, максимум 31), `MAX_PLAYERS` (16), `DIFFICULTY` (`regular`, также `recruit`/`veteran`), `MAP_ID` (`port` или `quarry`). Проверка готовности: `GET /health`. Сервер самостоятельно возобновляет раунд через 12 секунд после победы.

Можно развернуть приложенный Dockerfile на хостинге с поддержкой долгих WebSocket-соединений. `render.yaml` — конфигурация для Render; сервер в этом репозитории **не означает**, что отдельный облачный сервер уже оплачен или запущен.

## Публикация на GitHub Pages

В репозитории: **Settings → Pages → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` устанавливает зависимости, собирает Vite и публикует `dist`. Push в `main` обновляет игру. Относительные пути сборки поддерживают размещение в `/gpt-test/`.

GitHub Pages размещает статический клиент. Node.js-сервер из папки `server` на GitHub Pages не исполняется; сетевые комнаты используют браузер хозяина либо отдельно размещённый сервер.

## Архитектура и проверки

- `shared/world.js`: единая карта, параметры оружия и классов.
- `shared/simulation.js`: расчёт движения, попаданий, ботов, точек и билетов.
- `src/renderer.js`: Three.js, процедурные модели, оружие, эффекты и освещение.
- `src/network.js`: PeerJS/WebRTC и транспорт выделенного сервера.
- `src/audio.js`: оригинальная процедурная партитура и пространственная звуковая сцена Web Audio.
- `src/main.js`: управление, меню, настройки, HUD, миникарта и игровые переходы.
- `server/index.js`: HTTP/WebSocket, проверка команд и рассылка состояния.

Автотесты проверяют попадания и укрытия, захват и оспаривание точек, возрождение, защиту высадки, перезарядку, способности, гранаты, реакцию и очереди ботов, проходимость всех пяти точек от обеих баз, полный раунд, фильтрацию входных данных и взаимодействие двух настоящих WebSocket-клиентов. Они не заменяют испытания WebRTC на разных устройствах и сетях. Версия протокола 2 защищает от подключения клиентов со старой картой: после обновления всем игрокам нужно перезагрузить страницу и создать новую комнату.

Модели и текстуры создаются кодом; игровых материалов Battlefield нет. Шрифт загружается через Google Fonts с системными запасными шрифтами. Код проекта — MIT, зависимости распространяются по своим лицензиям.
