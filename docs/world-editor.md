# SECTOR 09 World Editor — этап 1

Ветка editor/world-editor. Первый поддерживаемый уровень: M05. Редактор работает только в Vite dev server, не является входной точкой production build.

Данные: shared/campaign/m05-editor-data.json. Версия 1: models (позиция XYZ в метрах, вращение XYZ в радианах, масштаб, локальные прямоугольные коллизии, detail, shadow), boxes (переопределения разрешённых препятствий), terrain (разреженные абсолютные значения сетки 409×409 с шагом 4 м), sites, routes, fuelRoutes, lighting, paint (цветовые пятна). Пустой файл не меняет карту. Существующая геометрия GLB и критические сценарные узлы защищены. Импортированные модели в public/world-editor-assets именуются SHA256; оригинальные M05 ассеты не перезаписываются. Сохранение проверяет ревизию, делает резервную копию в .perf-local/world-editor-backups и записывает атомарно.

Пока не реализованы универсальная миграция других карт, редактирование отдельных объектов из уже объединённых GLB, многослойные PBR-кисти, полноценный сценарный граф, катсцены, навигационный анализ и WebGPU viewport. Перестройка маршрутов миссии требует ручной проверки, а существующие дороги и запечённые объекты не перемещаются автоматически при изменении маршрутов или рельефа.
