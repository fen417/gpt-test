# SECTOR 09 World Editor — этап 1

Ветка editor/world-editor. Первый поддерживаемый уровень: M05. Редактор работает только в Vite dev server, не является входной точкой production build.

Данные: shared/campaign/m05-editor-data.json. Версия 1: models (позиция XYZ в метрах, вращение XYZ в радианах, масштаб, локальные прямоугольные коллизии, detail, shadow), boxes (переопределения разрешённых препятствий), terrain (разреженные абсолютные значения сетки 409×409 с шагом 4 м), sites, routes, fuelRoutes, lighting, paint (цветовые пятна). Пустой файл не меняет карту. Существующая геометрия GLB и критические сценарные узлы защищены. Импортированные модели в public/world-editor-assets именуются SHA256; оригинальные M05 ассеты не перезаписываются. Сохранение проверяет ревизию, делает резервную копию в .perf-local/world-editor-backups и записывает атомарно.

Пока не реализованы универсальная миграция других карт, редактирование отдельных объектов из уже объединённых GLB, многослойные PBR-кисти, полноценный сценарный граф, катсцены, навигационный анализ и WebGPU viewport. Перестройка маршрутов миссии требует ручной проверки, а существующие дороги и запечённые объекты не перемещаются автоматически при изменении маршрутов или рельефа.

## Запуск

Переключитесь на ветку editor/world-editor (или перенесите её изменения в рабочую папку). Запустите start-world-editor.bat. Требуется Node.js 24 и зависимости проекта. Git редактору не нужен. Откроется http://127.0.0.1:5178/world-editor.html. Используйте отдельное окно игры для проверки: после сохранения нажмите «Играть M05», откройте кампанию через меню и начните M05 заново, не продолжайте старый чекпоинт.

Редактор показывает исходную игровую геометрию M05, использует GameRenderer и игровой builder; динамические персонажи и часть динамического реквизита отсутствуют в предпросмотре. Прямая правка существующих GLB-батчей запрещена. В версии 1 разрешено двигать часть отдельно созданных укрытий, все новые модели, координаты существующих сюжетных точек и маршрутов. Импорт GLB работает с упакованными ресурсами; GLTF/FBX/OBJ преобразуются браузером, внешние текстуры должны быть выбраны вместе. Коллизии — составные прямоугольные, рассчитываются в общей физике. Добавьте коллизию вручную к препятствиям. Цветовая кисть не является PBR-покраской. Режим игры не стартует автоматически с позиции камеры; открывает меню игры с разблокированной кампанией.

Клавиши: ПКМ + WASD, колесо, средняя кнопка, F, W/E/R, Ctrl+D, Delete, Ctrl+S, Ctrl+Z/Y. В инспекторе углы в градусах; в JSON — радианы. Для импорта перетащите файл в viewport. Кнопка «Черновик JSON» скачивает копию текущих данных. Полный список невыполненных функций выше; этот этап не является законченным универсальным редактором.

## Этап 2 — материалы, расстановка, диагностика

- В инспекторе импортированной модели можно выбрать отдельный материал и изменить цвет, roughness, metallic, emissive, normal strength, AO, opacity, alpha test, двухсторонность. Изменения хранятся на уровне экземпляра и применяются в игре. Смена файлов текстур пока не реализована.
- Вращение каждого Box Collider по локальным XYZ. Объекты с физикой принудительно видимы на Low.
- Кисть расстановки: выбранный импортированный ресурс, количество объектов за штамп, случайные масштаб и yaw, минимальное расстояние, максимальный уклон, seed, минимальный графический пресет, тени. Ластик удаляет только экземпляры кисти выбранного ресурса. Кисть — декоративная, без физики. В игре статические непрозрачные экземпляры группируются в InstancedMesh по ресурсу и чанкам 48 м; анимированные, прозрачные и переопределённые экземпляры не объединяются.
- Библиотека импортированных ресурсов сохраняет имена, даже если на карте нет их экземпляров.
- В маршрутах можно вставлять и удалять контрольные точки. Дороги не перестраиваются автоматически.
- «Проверить карту»: ошибки схемы, неизвестные точки/маршруты, предупреждения о пересечении изменённых точек и участков маршрута с препятствиями, точках под землёй, отсутствии коллизии у новых обычных моделей. Это диагностика прямолинейных участков, не полноценный поиск пути.
