# SECTOR 09 World Editor — этап 1

Ветка editor/world-editor. Первый поддерживаемый уровень: M05. Редактор работает только в Vite dev server, не является входной точкой production build.

Данные: shared/campaign/m05-editor-data.json. Версия 1: models (позиция XYZ в метрах, вращение XYZ в радианах, масштаб, локальные прямоугольные коллизии, detail, shadow), boxes (переопределения разрешённых препятствий), terrain (разреженные абсолютные значения сетки 409×409 с шагом 4 м), sites, routes, fuelRoutes, lighting, paint (цветовые пятна). Пустой файл не меняет карту. Существующая геометрия GLB и критические сценарные узлы защищены. Импортированные модели в public/world-editor-assets именуются SHA256; оригинальные M05 ассеты не перезаписываются. Сохранение проверяет ревизию, делает резервную копию в .perf-local/world-editor-backups и записывает атомарно.

Пока не реализованы универсальная миграция других карт, редактирование отдельных объектов из уже объединённых GLB, многослойные PBR-кисти, полноценный сценарный граф, катсцены, навигационный анализ и WebGPU viewport. Перестройка маршрутов миссии требует ручной проверки, а существующие дороги и запечённые объекты не перемещаются автоматически при изменении маршрутов или рельефа.

## Запуск

Переключитесь на ветку editor/world-editor (или перенесите её изменения в рабочую папку). Запустите start-world-editor.bat. Требуется Node.js 24 и зависимости проекта. Git редактору не нужен. Откроется http://127.0.0.1:5178/world-editor.html. Используйте отдельное окно игры для проверки: после сохранения нажмите «Играть M05», откройте кампанию через меню и начните M05 заново, не продолжайте старый чекпоинт.

Редактор показывает исходную игровую геометрию M05, использует GameRenderer и игровой builder; динамические персонажи и часть динамического реквизита отсутствуют в предпросмотре. Прямая правка существующих GLB-батчей запрещена. В версии 1 разрешено двигать часть отдельно созданных укрытий, все новые модели, координаты существующих сюжетных точек и маршрутов. Импорт GLB работает с упакованными ресурсами; GLTF/FBX/OBJ преобразуются браузером, внешние текстуры должны быть выбраны вместе. Коллизии — составные прямоугольные, рассчитываются в общей физике. Добавьте коллизию вручную к препятствиям. Цветовая кисть не является PBR-покраской. Режим игры не стартует автоматически с позиции камеры; открывает меню игры с разблокированной кампанией.

Клавиши: ПКМ + WASD, колесо, средняя кнопка, F, W/E/R, Ctrl+D, Delete, Ctrl+S, Ctrl+Z/Y. В инспекторе углы в градусах; в JSON — радианы. Для импорта перетащите файл в viewport. Кнопка «Черновик JSON» скачивает копию текущих данных. Полный список невыполненных функций выше; этот этап не является законченным универсальным редактором.

## Этап 2 — материалы, расстановка, диагностика

- В инспекторе импортированной модели можно выбрать отдельный материал и изменить цвет, roughness, metallic, emissive, normal strength, AO, opacity, alpha test, двухсторонность. Изменения хранятся на уровне экземпляра и применяются в игре. Смена файлов текстур пока не реализована.
- Вращение каждого Box Collider по локальным XYZ. Объекты с физикой принудительно видимы на Low.
- Кисть расстановки: выбранный импортированный ресурс, количество объектов за штамп, случайные масштаб и yaw, минимальное расстояние, максимальный уклон, seed, минимальный графический пресет, тени. Ластик удаляет только экземпляры кисти выбранного ресурса. Кисть — декоративная, без физики. В игре статические непрозрачные экземпляры группируются в InstancedMesh по ресурсу и чанкам 48 м; анимированные, прозрачные и переопределённые экземпляры не объединяются.
- Библиотека импортированных ресурсов сохраняет имена, даже если на карте нет их экземпляров.
- В маршрутах можно вставлять и удалять контрольные точки. Дороги не перестраиваются автоматически.
- «Проверить карту»: ошибки схемы, неизвестные точки/маршруты, предупреждения о пересечении изменённых точек и участков маршрута с препятствиями, точках под землёй, отсутствии коллизии у новых обычных моделей. Это диагностика прямолинейных участков, не полноценный поиск пути.

Проверка браузера в CI: отдельный сценарий Playwright запускает редактор в Chromium (SwiftShader), импортирует синтетическую GLB, добавляет Box, меняет roughness, сохраняет и открывает карту заново. Аппаратные FPS этим тестом не измеряются. Кисть обновляет только затронутые тайлы ландшафта.

## Этап 3 — слои грунта и дороги

Кисть «Материал» наносит землю, бетон, асфальт или песок с реальными текстурами, normal map на высоких пресетах и маской смешивания. Данные хранятся как слои, обрабатываются общим игровым builder. Новый сплайновый инструмент: точки на поверхности, ширина и материал, перемещение/вставка/удаление точек, явная операция выравнивания высот. Дороги не являются навигационными маршрутами. Редактирование катсцен и сценариев отложено по запросу пользователя. Пока поддерживается M05; прочие карты и создание с нуля ещё не подключены.

## Новые карты

Кнопка «+ Карта» создаёт плоскую тестовую карту размером 128–1024 м (кратно 32) с двумя командными спавнами. Используются те же инструменты рельефа, материалов, дорог, импорта и коллизий. Карты хранятся в shared/editor-maps.json; спавны spawnA и spawnB автоматически следуют за высотой земли. «Играть» открывает одиночное меню с выбранной картой (TDM с классовым оружием); нажмите кнопку старта одиночной игры. Карты доступны только в локальном dev-режиме; сетевой и публичный режимы пока не регистрируют их. Импорт остальных старых карт остаётся отдельной задачей.

## Работа с несколькими моделями

Ctrl+клик добавляет или снимает модель из выделения; Shift+клик выбирает всю именованную группу. «Все модели» выделяет все импортированные экземпляры. Групповое перемещение и вращение выполняются через общий pivot, равномерное масштабирование — через коэффициент в инспекторе, без искажения неравномерных масштабов. Ctrl+C/V, Ctrl+D, Delete работают с несколькими моделями. Группы сохраняются в JSON как метаданные, не изменяя физику или иерархию игровых объектов.

## Игровые точки новых карт

Для локальных карт доступны режимы TDM и захват, дополнительные командные спавны, точки захвата (до 26), танк, Хамви и квадроцикл. Размещение кликом по поверхности, точные координаты и направление в инспекторе. Для захвата нужна хотя бы одна точка. M05 сохраняет собственную логику. Сетевые карты не публикуются автоматически. Лимит стартового JavaScript теперь рекомендательный; ограничения аудио остаются обязательными.

## Heightmap

Импорт бинарного PGM P5 (8/16 бит) или обычного изображения PNG/JPEG (8-битная яркость). Экспорт PGM P5 16 бит; чёрный и белый соответствуют выбранным нижней и верхней высоте, допустимо −80…180 м. Для M05 охватывает сетку 409×409; для новой карты только игровую область, округлённую по шагу 4 м. Строки идут в сторону увеличения Z. Для точного обмена используйте одинаковый диапазон при импорте и экспорте. Импорт заменяет высоты и поддерживает Undo; запечённые объекты не перемещаются автоматически.

## Исходные декорации и навигация

M05: в фильтре «Группы декораций M05» доступны исходные пространственные батчи `m05_set_*` и `m05_detail_*`. Можно перемещать, вращать, равномерно масштабировать, скрывать и восстанавливать группу. Коллизии соответствующих исходных props, включая части составных коллизий, меняются одновременно. Индивидуальное редактирование предметов внутри батча и промышленных сюжетных моделей ещё не поддерживается.

«Пересчитать сетку» запускает игровую Simulation в отдельном Web Worker, без ботов и без запуска матча. Цветные узлы показывают проверку стоя/присев/заблокировано на высоте грунта. «Проверить путь A → B» использует игровой поиск пути, включая возврат частичного результата. Это проверка статической геометрии, а не полная симуляция сюжетных дверей, движущихся объектов или поведения ИИ. После изменения карты расчёт инвалидируется.

## Локальное освещение

Point/Spot добавляются кликом по земле. Параметры: позиция, цвет, мощность, дальность, минимальный уровень детализации; для Spot — направление по XYZ, полуугол, мягкость края, тень High. В редакторе и игре действует предел одновременно активных ламп: Low 2, Medium 4, High 8; на High максимум две тени от прожекторов. Приоритет — порядок добавления. До 24 ламп на карту. Это намеренные ограничения для слабых GPU, отдельные запечённые lightmap не генерируются.

## Отдельные исходные декорации M05

Один раз запустите `prepare-m05-editor-source.bat` (если Blender не найден, передайте путь к blender.exe). Скрипт открывает существующий `dressing.blend`, экспортирует только именованные исходные предметы в `public/campaign/m05/dressing-source.glb` и упаковывает Meshopt; исходный .blend и основной GLB не изменяются. Перезапустите редактор. Фильтр «Отдельные декорации M05» позволяет двигать, вращать, масштабировать и удалять отдельные предметы, синхронно с коллизиями. Позиции в инспекторе локальны относительно батча. В игре заменяются только затронутые группы; новая геометрия объединяется по материалу, нетронутые группы остаются в исходном GLB. При передаче карты другим пользователям включите сгенерированный GLB, если есть индивидуальные правки. Без него прежнее редактирование батчей доступно как раньше.

## Анализ и Meshopt импортированных моделей

В инспекторе отображаются треугольники, меши, оценка draw calls, габариты, размер буферов и примерная VRAM текстур. Опциональный флажок при импорте или отдельная кнопка Meshopt запускают сжатие через glTF Transform. Исходный GLB остаётся в библиотеке; оптимизированный файл получает новый SHA256. Если результат не меньше, используется оригинал. Перестройка порядка вершин не уменьшает число треугольников и не является LOD или KTX2. Смена текстур и генерация LOD пока отдельно не реализованы.

Для пользователей без Blender предусмотрена отдельная GitHub Actions сборка «Export editable M05 source». Артефакт `m05-editor-source` содержит готовый `dressing-source.glb`; распакуйте файл в `public/campaign/m05/`. Проверка сравнивает все исходные ID, координаты, вращение и масштаб с M05_DRESSING. Экспорт также можно запустить вручную в Actions. CI не меняет репозиторий автоматически.

## Наклон и импорт

В инспекторе X/Z — наклон, Y — поворот. «По склону» выравнивает локальную вертикаль по нормали грунта и опускает модель до земли, «Сбросить наклон» убирает X/Z. Перед импортом можно задать масштаб, включить выравнивание и автоматический Box Collider. Можно выбрать несколько GLB и импортировать их за один раз; GLTF/FBX/OBJ выбираются по одному с сопутствующими файлами. Автоматический Box — только габариты, для дверей и сложных сооружений используйте составные коллизии.

## Копии существующих карт

В верхней панели рядом с «+ Карта» выберите Пустая, Порт, Карьер или Деревня. Для существующей карты создаётся локальная копия исходного layout. Доступны исходные процедурные объекты, изменение X/Z, вращение XYZ, масштабирование, удаление, импорт моделей, локальный свет и навигация. Исходные коллизии перестраиваются через штатный applyMapEdits; оригинальные карты не перезаписываются. У большинства исходных объектов высота определяется штатным грунтом. Предпросмотр и тестовый матч используют процедурный fallback, не оригинальные запечённые GLB; качество может отличаться. Рельеф, дороги, игровые правила исходной карты пока защищены, новые пустые карты редактируются как прежде. Laguna и Linden Estate ещё не подключены.

«По склону» сохраняет горизонтальное направление и выравнивает локальную вертикаль по нормали. При опускании учитывается контакт вершин с высотой грунта, а не только нижняя точка мирового AABB. Это приближённая установка для сложной геометрии, не физическая симуляция падения.
