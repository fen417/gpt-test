# Редактор хвата SECTOR 09

Локальный инструмент для редактирования FPS-моделей рук. Не включается в сборку игры и не доступен через GitHub Pages.

## Запуск
1. Установите зависимости: `npm install`.
2. Запустите `npm run dev` из корня проекта.
3. Откройте `http://127.0.0.1:5173/grip-editor.html` (если Vite выбрал другой порт, используйте его).
4. Выберите оружие, руку и палец. Перетаскивайте ползунки X/Y/Z либо вводите числа в миллиметрах. Кисть можно также поворачивать вокруг запястья в градусах.
5. Нажмите «Сохранить хват». Изменения записываются в `src/assets/grip-overrides.json` и подхватываются игрой после обновления страницы. Чтобы опубликовать, закоммитьте этот файл.

Blender необходим для изменения пальцев. Скрипт ищет Blender 5.3 в стандартном каталоге Windows или команду blender в PATH. Можно задать путь перед запуском Vite:

```powershell
$env:BLENDER_EXE = "C:\Program Files\Blender Foundation\Blender 5.3\blender.exe"
npm run dev
```

При первом редактировании пальца Blender экспортирует исходную геометрию перчаток; затем она кэшируется в процессе Vite. Пальцы пересчитываются через существующий IK/ретаргетинг, не через растяжение вершин по расстоянию. Ручной запуск assets:hands не требуется. Положение и вращение кисти не требуют Blender.

## Особенности
- Все 10 моделей имеют независимые профили обеих рук; обычная поза и морф спуска/раскрытия сохраняются вместе.
- Пистолеты используют одноручную стойку: при выборе левой руки автоматически показывается перезарядка.
- Для пальцев задаётся цель кончика, а не произвольное растяжение фаланг. Слишком удалённая цель может быть недостижимой. Проверяйте пересечения с оружием визуально.
- Поворот кисти выполняется вокруг её запястья, рукав следует за смещённой кистью.
- Настройки не влияют на третье лицо, баллистику, сетевые данные и гаджеты. При броске гранаты и работе с гаджетами используются исходные руки.
- Удаление профиля восстанавливает стандартный хват.
